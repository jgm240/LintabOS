# LintabOS 0.3.0 (pre-release)

Built from real-tablet feedback: someone is now running LintabOS on a Duet 3, so this release adds the tools to find and fix hardware
problems, a way out if you change your mind, and more to do with the tablet.

- **Folio not working.** A new mode in **Tablet & Folio**: the on-screen keyboard stays available even with the folio attached, and the
  folio keeps working. For folios with faulty keys.
- **Remove LintabOS.** From the live USB, give the space back to Windows and clean up the boot entries. It refuses if no Windows is on the
  disk, deletes only a partition it can identify as LintabOS, and writes a partition-table backup first.
- **Update rollback.** A verified copy of the previous version is kept, a health check runs after installing, and a broken update rolls
  itself back. `lintab-update rollback` or the button in LintabOS Updates does it by hand.
- **Hardware Report.** Collects Wi-Fi, Bluetooth, fingerprint, sensor, camera, folio, battery, storage and sleep/resume details with
  identifying data masked. Nothing is sent; you read it and paste it into a GitHub issue. `lintab-hwcheck` now checks Wi-Fi and Bluetooth too.
- **LintabOS Extras.** Rnote and Xournal++ for drawing, the Office pack, Waydroid for Android apps and Bottles for Windows programs, all
  optional downloads.
- **Reading Mode** and default auto-brightness; **Battery Health** with a charge limit where the firmware allows one.

## Known issues (reported on a real Duet 3, not fixed yet)

- **Wi-Fi disappeared.** Cause unknown.
- **Fingerprint login doesn't work.** Cause unknown.
- **Power button or closing the folio freezes the tablet** until a force restart, most likely suspend that doesn't resume. Workaround:
  `sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target`.

Please send a **Hardware Report** from an affected tablet. These three are the next things to fix.

## What was checked

- Remove LintabOS on real loop-device disks (512- and 4096-byte sectors): partitions, Windows' data, boot files and firmware entries
  verified; the space is left alone when Windows is flagged or no Windows is present.
- Update rollback with a fake GitHub and real signatures, including automatic rollback and a tampered saved copy.
- Unit tests for the report's masking, Extras, reading mode and battery maths; the package installs, upgrades and removes cleanly.

## Not checked

Everything on the tablet itself, Waydroid, Bottles, pen drawing, the ambient light sensor and charge-limit support.
