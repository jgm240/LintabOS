# LintabOS 0.3.7 (pre-release)

A reported touchscreen problem, with no real diagnostic for it yet.

## What's new

**Hardware Report** now has a dedicated Touchscreen section: whether `udev` tags any input device as a
touchscreen (`ID_INPUT_TOUCHSCREEN=1`), what `libinput` — what GNOME's input stack actually uses — sees for
it, and the kernel's own log messages about the touch controller (`i2c_hid`, `hid-multitouch`, and the usual
touch-chip driver names). The old "Keyboard, folio and touch" section is now "Keyboard and folio"; touch gets
its own section.

## Not fixed yet

This is diagnostics, not a fix — there isn't enough information yet to know what's actually wrong (missing
driver, a udev tagging gap, a libinput quirk, or something else). Same first step as `lintab-wifi-fix` before
it: find out what's really happening before guessing at a repair.
