# LintabOS 0.3.14 (pre-release)

Another real-hardware bug, found and fixed live against the same Duet 3: LinWinMod's "pick any NTFS partition by
hand" picker wasn't actually showing every NTFS partition.

## What was found

`WINRE_DRV`, the tablet's Windows Recovery Environment partition, is genuinely NTFS-formatted - confirmed live
(`fstype=ntfs`) - but it carries the Windows Recovery Environment GPT type (`de94bba4-...`), not the Microsoft
basic data type (`ebd0a0a2-...`) that `list_microsoft_data_partitions()` matched on. The picker's whole point is
to find NTFS partitions automatic detection misses, by GPT type rather than fragile content-probing - but it was
only checking for *one* of the GPT types a real NTFS partition can carry, so WinRE silently never appeared in it.

Fixed: `list_microsoft_data_partitions()` now also matches the Windows Recovery Environment GPT type. Confirmed
live: `WINRE_DRV` now appears in the picker's results on the real tablet.

## Also in this release

- The BCD write's power gate (`lintab.bcdbackup`) no longer requires AC power to be connected - only the 40%
  battery minimum remains. Being tethered to a charger just to use the tool was more friction than the marginal
  protection it added once the battery threshold already covers the case that matters (a power loss mid-write).
