# LintabOS 0.3.10 (pre-release)

A real-hardware result for the "Restart into Windows Recovery" feature from 0.3.9, tested by a user on an actual
Duet 3 within a day of release.

## What was found

Setting the UEFI `OsIndications` variable's "start OS recovery" bit before rebooting **does not** open Windows'
Troubleshoot/Advanced Options menu. What it actually does: a brief "Automatic Repair on drive C:" screen — Windows'
own Startup Repair diagnostic — which finds nothing wrong and boots normally.

This is a different, narrower mechanism than the one this was aiming for, confirmed by a real test rather than
left as an open question. It's being kept: it's a genuine, harmless effect (not a silent no-op), and on a tablet
that actually has a startup problem, it's one more chance for Windows' own repair tools to catch it. The real,
reliable way into Recovery and Safe Mode — shown every time, not as a fallback — is unchanged: Settings → Recovery
→ Advanced startup, or holding Shift while choosing Restart from within Windows (a Windows feature, unrelated to
this UEFI variable or anything LintabOS writes).

## Documentation corrected

Both `docs/LEGAL.md` and the README previously said this was "not independently confirmed to work on Windows." That
hedge is replaced with the real, tested result throughout: LintabOS now describes exactly what happens, not what
might happen.
