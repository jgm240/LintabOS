# LintabOS 0.2.0 (pre-release)

Seven new things, all aimed at using the Duet 3 as a tablet and at living next to Windows.

- **Automatic tablet mode.** Detach the folio keyboard and the on-screen keyboard appears; attach it and it goes away.
  A **"Keyboard Attached" / "Keyboard Detached"** notification and a short snap sound play each time. Override with
  `lintab-tablet-mode auto|tablet|laptop`.
- **School mode.** One switch (the **School Mode** app) turns every camera off: drivers blocked, device nodes locked, USB webcams
  de-authorized. Turning it on needs no password; turning it off needs an administrator's password.
- **Windows files in the sidebar.** When you install next to Windows, its drive shows as **Windows** in Files (read-only; mounted when
  first opened). Existing installs: `sudo lintab-windows-files enable`.
- **Touch boot menu (optional).** The **Touch Boot Menu** app installs rEFInd next to GRUB with big LintabOS and Windows icons. GRUB and
  Windows are untouched and it can be switched off again. It refuses to turn on while **Secure Boot is on**.
- **KDE Plasma and Xfce, touch-friendly (optional).** Turn them on in the installer; they are downloaded during setup (about 450 MB and
  70 MB, internet needed) after GRUB is installed, so a failed download cannot affect booting. GNOME stays the default login. Plasma
  gets the Maliit keyboard and a bigger panel; Xfce gets a bigger panel, cursor and interface, the Onboard keyboard and screen
  rotation that follows the accelerometer. The tablet-mode keyboard switch and the attach/detach message work in all three desktops.
- **Word, Excel, PowerPoint, OneDrive and Teams.** Microsoft's web apps in their own windows, one shared sign-in; *Connect OneDrive to
  Files* adds your account to Files. **Native Office and Teams don't exist for Linux**; the optional **Office Pack** downloads LibreOffice
  and an unofficial Teams app from Flathub.

## What was checked

- 46 new tests (`./scripts/test-features.sh`): the desktop installer (order, GDM stays default, offline failure, DNS), touch settings and
  Xfce rotation maths; keyboard detection, notification/sound decisions, generated school-mode files (udev rules
  verified with `udevadm verify`), the fstab block, and the boot menu against a fake firmware and EFI partition (including the refusal under
  Secure Boot and a clean `disable`).
- The package installs, upgrades and removes cleanly on Debian 13 and contains every new file; the tablet-mode service is enabled for all users.

## Known issues

- **Not tested on the tablet.** Specifically: whether detaching the folio is seen as a keyboard disappearing, whether cameras are really dead
  in school mode on the Duet, and rEFInd's look and touch response (rEFInd touch depends on the firmware), and real KDE/Xfce sessions (only package lists, settings
  keys and logic were checked).
- Updating from 0.1.0 with **LintabOS Updates** installs the new tools and web-app launchers. Chromium, Flatpak and the sound player are
  recommended packages that the updater does not pull in; without Chromium the web apps open in Firefox.
- The GRUB live-USB menu still shows GRUB's default look (cosmetic).
