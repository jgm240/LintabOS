# LintabOS 0.3.2 (pre-release)

- **LinWinMod.** A GUI for the Windows side of a dual-boot install:
  - **Files**: opens the Windows drive read-write in Files, with the same Fast-Startup/BitLocker safety checks as
    *Windows Files → --read-write*. No new capability over what's already there, just a direct way to reach it.
  - **Registry**: browse SOFTWARE, SYSTEM, DEFAULT and each user's own hive — **read-only, with no exceptions**. There is no
    write path to the registry anywhere in LinWinMod. **SAM and SECURITY are refused outright**, at the function that opens a
    hive rather than just left off a menu, because they hold password hashes and cached credentials directly. `docs/LEGAL.md`
    explains why a write-capable editor with a blocklist was considered and rejected.

## What was checked

27 new tests, including real registry reads (every value type, nested keys, an empty key, a missing path, search) against a
real hive built from the `hivex` project's own upstream test fixture, and the SAM/SECURITY refusal under several path
spellings including a file that is a genuinely valid, openable hive. The package installs, upgrades and removes cleanly.

## Not checked

A real Windows installation's actual registry hives, and the file manager against a real NTFS mount — both need a real
dual-boot tablet, which these tests don't have. The Wi-Fi, fingerprint and sleep problems reported on the Duet 3 are
unrelated and still open.

Files: `lintabos-0.3.2-amd64.iso`, `lintabos-core_0.3.2_all.deb` + `.minisig`, `SHA256SUMS`.
