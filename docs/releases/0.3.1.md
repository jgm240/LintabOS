# LintabOS 0.3.1 (pre-release)

- **Android Mode, with a way out.** Install *Android apps (Waydroid)* from LintabOS Extras, then open **Android Mode** to turn the whole
  tablet into a full-screen Android tablet (Waydroid inside `cage`, the setup Waydroid's own documentation describes). It uses an "Android"
  login session: it logs you out and you sign in again into Android.
  - **Computer Mode** is an app inside Android (LintabOS installs it for you). Open it to leave: the session ends and you sign in to your
    normal desktop again.
  - **The power button is Android's power button** while you are in Android mode. The host's own reaction to it, to the folio and to the
    sleep keys is held back so the tablet can't be turned off or put to sleep by accident.
  - It fails closed: if the Computer Mode listener can't start, the session ends at once instead of leaving you without a way out. A keyboard
    can still use Ctrl+Alt+F3.
- **The Microsoft 365 web apps are optional.** They are no longer installed for everyone. Add them from **LintabOS Extras → Microsoft 365 web
  apps** (it downloads Chromium first if needed). If you had the shortcuts, they disappear from the app grid when you update to this version;
  add them again from Extras.
- **Every extra can be removed.** *Remove extras…* (in the LintabOS Extras menu, or `lintab-extras remove KEY`) uninstalls Rnote and Xournal++,
  the Office pack, Bottles, the Microsoft shortcuts (and forgets their sign-in) or Waydroid (which deletes the Android image and everything
  inside Android; it says so first). Your own documents and notes are kept.
- Chromium is no longer in the ISO, which makes it smaller.

Not tested on the tablet: Waydroid itself, touch and orientation under cage, whether Android can reach the Computer Mode listener on a real
Waydroid network (a firewall rule could block it), and whether the power key reaches Android. The Wi-Fi, fingerprint and sleep problems from
0.3.0 are still open; `sudo lintab-wifi-fix` and the **Hardware Report** are there to help find them.

Files: `lintabos-0.3.1-amd64.iso`, `lintabos-core_0.3.1_all.deb` + `.minisig`, `SHA256SUMS`.
