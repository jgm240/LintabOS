# LintabOS 0.1.0 (pre-release)

Debian 13 + GNOME + GDM, tuned for the **Lenovo IdeaPad Duet 3 (11IAN8)**, with a touch-first installer, a dual-boot
partitioner that can shrink Windows, a **Boot into Windows** GRUB entry, BitLocker tools (dislocker), and an updater that pulls
signed releases from this repository.

> **This is an early pre-release that has not been tested on the tablet yet.** It boots under UEFI in an emulator and its
> installer, partitioner and BitLocker code are tested against synthetic disks, but nobody has installed it next to a real
> Windows yet. **Back up your data first.** Turning BitLocker off from the installer rewrites your whole Windows partition;
> turning it off inside Windows is the safer route. See the [README](https://github.com/jgm240/LintabOS#honest-status-what-has-and-hasnt-been-tested).

## What was checked

- The ISO boots under UEFI (in an emulator), reaches the GNOME desktop, shows the LintabOS boot splash, and starts the installer
  by itself ("Welcome to LintabOS"), with Files, Firefox, the camera app, Settings, "Restart into Windows" and the updater in the dock.
- The installer, partitioner and BitLocker code pass their tests against synthetic disks; the `lintabos-core` package installs, upgrades and
  removes cleanly on Debian 13; the updater rejects tampered, wrongly signed, swapped and downgraded packages in tests.

## Known issues

- **Not tested on the tablet** (see above). Camera, sensors, fingerprint and the installer on a real Windows disk are untested.
- The GRUB menu on the live USB currently uses GRUB's **default look**; the themed menu with the logo does not load yet (cosmetic;
  the menu works). A fix is planned for 0.1.1 and will reach installed systems through **LintabOS Updates**.
- The first lines of an emulated boot show `mount: ... unknown filesystem type 'efivarfs'` from the initramfs; it is harmless.

## Files

- `lintabos-0.1.0-amd64.iso`: the live/installer image (UEFI; Secure Boot works with Debian's shim). Verify it against `SHA256SUMS`.
- `lintabos-core_0.1.0_all.deb` + `.minisig`: the LintabOS parts as a package. This is what **LintabOS Updates** installs on
  existing systems; you normally don't download it by hand.

## Write the ISO to a USB stick

```bash
diskutil list                         # find the stick, e.g. /dev/disk5
diskutil unmountDisk /dev/disk5
sudo dd if=lintabos-0.1.0-amd64.iso of=/dev/rdisk5 bs=4m status=progress
```
